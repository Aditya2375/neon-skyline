neon-skyline

Your year on GitHub, as a New York skyline.

One tower per week. Each tower has seven window columns, one per weekday, and the lit windows in a column rise with that day's contributions. Landmarks stand behind the data towers.

Use it for your own account

GITHUB_TOKEN=<token> node skyline.mjs <your-login> skyline.svg

Any token that can read public data works. Needs Node 18 or newer. Embed the result with ![skyline](skyline.svg). It is one file with no scripts and no outside requests.

Reading it honestly

Tower height is the square root of the week's total, so a quiet week is a stub, not an empty slot. The landmarks are decoration and carry no data. The animation (twinkling windows, beacons, car lights, ripples, a ferry and a plane) stops for readers who prefer reduced motion.
